数据存放在你的 GitHub 仓库，发布后电视大屏自动拉取更新（无需服务器）
脱敏说明：发布时系统会自动对「会议内容 / 小结 / 标题 / 地点」执行文本脱敏（姓名→「该同志」、手机号/身份证/邮箱掩码）， 并对党员名册进行聚合统计与职务泛化。公开发布的数据不含任何真实姓名、手机号、身份证与邮箱。

① 连接你的 GitHub 仓库

本后台直接通过 GitHub API 把数据写入你的仓库（相当于「后台上传数据」）。需要：
1）一个 GitHub 仓库（建议公开，显示数据已脱敏不含姓名/电话）；
2）一个 Personal Access Token（PAT），勾选 repo 权限。 生成地址：github.com/settings/tokens
令牌仅保存在本浏览器 localStorage，不会上传到任何第三方。
